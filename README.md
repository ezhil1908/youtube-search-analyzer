# YouTube Search Analyzer

A Python-based data analytics project for analyzing YouTube search results and extracting meaningful insights from video data.

## 📌 Project Overview

The YouTube Search Analyzer collects and processes YouTube video data and performs analysis to understand different characteristics and patterns within the search results.

The project includes data cleaning, analysis, sentiment analysis, and visualization components.

## 🎯 Objectives

- Collect and organize YouTube video data
- Clean and prepare the dataset for analysis
- Analyze video-related metrics
- Perform sentiment analysis
- Generate visualizations and insights
- Present the results in an easy-to-understand format

## 🛠️ Technologies Used

- Python
- Pandas
- Data Analysis
- Data Visualization
- Sentiment Analysis
- YouTube API
- CSV Data
- Git & GitHub

⚙️ Installation

Clone the repository:git clone https://github.com/ezhil1908/youtube-search-analyzer.git
Navigate to the project directory:cd youtube-search-analyzer
Create and activate a virtual environment:python -m venv venv
Activate the virtual environment on Windows:venv\Scripts\activate
Install the required dependencies:pip install -r requirements.txt

▶️ Usage

Run the application using: python app.py

Individual analysis components can also be executed using the corresponding Python files.
